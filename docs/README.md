# AppCreate プロジェクト全体ドキュメント

このディレクトリには、特定のアプリ (apps/solara 等) に紐づかない、**プロジェクト横断のノウハウ**を置く。

個別アプリのドキュメントは `apps/<app_name>/docs/` 配下に置く。

## 追加方針

- 1 アプリ固有の話は `apps/<app>/docs/` に書く (汎用ノウハウ部分だけ後でここに昇格)
- ドキュメントは "将来の自分 or 別の開発者" が読んで使える形に書く
- 既存事例 (= 過去の失敗) を引用すると説得力が増す
