# 惑星紹介テキスト 全文一覧 (Map 画面 タップ popup)

Map 画面の惑星マーカーをタップしたときに表示されるテキストの**全文ダンプ**。

データソース: [`lib/utils/planet_intro.dart`](../lib/utils/planet_intro.dart)
表示ロジック: [`lib/screens/map/map_planet_intro_popup.dart`](../lib/screens/map/map_planet_intro_popup.dart)

## トーン規約

- 詩的な短文 + 改行のリズム
- 「あなた」呼称・優しく語りかける
- 占星術用語より、体験的な比喩 (光・風・種・地層・潮)
- 「司る」「課題」より「授ける」「贈る」「灯す」
- 静かな伴走感 (Stella/Solara が見守るニュアンス)

## データ構造

各惑星につき以下の **8 フィールド** を保持。

| フィールド | 用途 |
|---|---|
| `coreSummary` | コア機能 1行サマリ |
| `coreDetail` | コア機能 詳細 |
| `natal.summary` | 出生フレーム 1行サマリ |
| `natal.detail` | 出生フレーム 詳細 |
| `transit.summary` | 経過フレーム 1行サマリ |
| `transit.detail` | 経過フレーム 詳細 |
| `progressed.summary` | 進行フレーム 1行サマリ |
| `progressed.detail` | 進行フレーム 詳細 |

10 惑星 × 8 フィールド = **80 テキストブロック** を本ドキュメントで全件収録。
これに加えて popup 側の固定文言を末尾に列挙。

# ☉ 太陽 (sun)

## コア機能

### coreSummary
```
あなたという光が、なんのために灯されたかを照らす星。
```

### coreDetail
```
太陽は、あなたの中心。
人生という旅路で、どこへ向かおうとしているのか、
本当のあなたはどんな顔をしているのか ―
それを静かに照らし続ける光です。

月が「夜の声」なら、
太陽は「あなたが生まれる前から決めてきた、生きる方向」。
```

## Natal (出生)

### natal.summary
```
あなたが生まれた日、世界に贈った「私の本質」。
```

### natal.detail
```
あなたが生まれた瞬間、太陽はあなたに「中心の灯」を授けました。
なんのために生まれてきたのか、
どんな自分でいるとき最も自分らしいのか ―
その答えがここに、静かに記されています。

まわりの期待に揺れたときは、
この光に戻ってきてください。
あなたを最初から知っているのは、ここの太陽だけです。
```

## Transit (経過)

### transit.summary
```
空の太陽が、約1ヶ月ごとに季節の主題を運んでくる。
```

### transit.detail
```
空の太陽は、1年で12星座を一周します。
滞在する1ヶ月のあいだ、その星座のテーマで
あなたのまわりに季節が立ち上がります。

誕生月のソーラーリターンは、
その先1年に生きる主題が、静かに決まる時。

誕生日が近づいたら、空を見上げてみてください。
あなただけの一年が、また始まります。
```

## Progressed (進行)

### progressed.summary
```
内なる太陽が、約30年かけて人生の大章を替えていく。
```

### progressed.detail
```
プログレスの太陽は1年で約1度進み、
30年でひとつの星座を渡ります。

ナタル太陽は「生まれ持った原型」。
プログレス太陽は「いまここで生きている、現在の主役」。

進行太陽が次の星座へ進んだとき、
人生のテーマが静かに、しかし決定的に切り替わります。
30歳前後、60歳前後 ― そんな大きな転機の正体は、
たいてい、この星です。
```

```
生まれつき、あなたの中で霧が立ちのぼる場所。
```

### natal.detail
```
生まれた瞬間、海王星はあなたに「夢みる力」を授けました。
なにに憧れるのか、
なにに胸が震えるのか、
どこで現実が美しい霧に包まれるのか ―
その素質がここに記されています。

この星は、ときに人を迷わせます。
けれど芸術や祈りや、無条件の愛は、
いつもこの星から生まれています。
```

## Transit (経過)

### transit.summary
```
空の海王星が、14年かけてあなたの夢の景色を変える。
```

### transit.detail
```
空の海王星は、14年でひとつの星座を渡ります。
滞在中の星座のテーマで、
長い時間をかけた憧れと、ぼんやりとした霧を贈ります。

はっきりとした出来事として現れにくく、
気づけば「いつのまにか、こちらの世界に来ていた」 ―
そんな静かな移行を起こす星です。

抗わずに、流れに身をあずけてみてください。
```

## Progressed (進行)

### progressed.summary
```
進行はほぼ止まって見える。一生かけて夢を熟成させていく。
```

### progressed.detail
```
プログレスの海王星は、ほとんど動きません。
一生のあいだに、わずかしか進みません。

だからこの星は、
「あなたの一生を貫く憧れの方向」を見る指標です。

ナタル海王星のとなりに、ずっと寄り添うようにいて、
あなたの夢を、長い時間かけて、ゆっくりと熟成させていきます。
```

# ♇ 冥王星 (pluto)

## コア機能

### coreSummary
```
奥底にある根源の力。壊して、生まれ変わるための星。
```

### coreDetail
```
冥王星は、根を揺さぶる星。
表面の取り繕いをはがし、
本当の力、本当の執着、本当の恐れを露わにします。

死と再生、隠された資源、深い変容 ―
すべて、冥王星の領分にあります。

公転 248 年。
一生のうちで、ひとつかふたつの星座しか進みません。
```

## Natal (出生)

### natal.summary
```
生まれつきあなたが抱えている、最も深い力と執着。
```

### natal.detail
```
生まれた瞬間、冥王星はあなたに「奥底の力」を授けました。
いちばん手放したくないもの、
いちばん壊されたくないもの、
けれど壊れたとき、いちばん深い場所から再生してくる力 ―
その源がここにあります。

この星は、軽く扱うことができません。
けれど人生の本当の底力は、
いつもここから湧いてきます。
```

## Transit (経過)

### transit.summary
```
空の冥王星が、約20年かけてあなたの奥底を作り変える。
```

### transit.detail
```
空の冥王星は、20年でひとつの星座を渡ります。
滞在中の星座のテーマで、
長い時間をかけた変容が、静かに進みます。

変化が始まったときには気づきません。
振り返ったとき、
「あの頃の私は、もうここにはいない」と分かる ―
それが、冥王星の仕事です。

通り過ぎたあと、あなたは別の人として立っています。
```

## Progressed (進行)

### progressed.summary
```
進行はほぼ止まって見える。一生をかけて深まっていく主題。
```

### progressed.detail
```
プログレスの冥王星は、一生のあいだに 1 度にも満たないほど
わずかしか動きません。

だからこの星は、タイミングを見る星ではなく、
「あなたが一生をかけて深めていく主題」が
いま、どう熟成しているかを見る指標です。

ナタル冥王星と寄り添いながら、
あなたの最も深いところを、
長い時間をかけて成熟させていきます。
```

# Popup 固定文言 (planet_intro.dart 外)

`planet_intro.dart` ではなく、popup widget 側 ([`map_planet_intro_popup.dart`](../lib/screens/map/map_planet_intro_popup.dart)) でハードコードされている文言。

## フレームバッジラベル

惑星名の右下に表示される小さなバッジ。

| frame キー | 表示テキスト | アクセント色 |
|---|---|---|
| `natal` | `出生 NATAL` | `#E9D29A` (ゴールド) |
| `transit` | `経過 TRANSIT` | `#FF8E5C` (オレンジ) |
| `progressed` | `進行 PROGRESSED` | `#63D6A0` (緑) |

## コアセクション見出し

popup 下部のコア機能ボックスの上に表示されるラベル。
`{惑星日本語名} の基本` のテンプレートで生成される。

```
太陽 の基本
月 の基本
水星 の基本
金星 の基本
火星 の基本
木星 の基本
土星 の基本
天王星 の基本
海王星 の基本
冥王星 の基本
```

## プレースホルダ (通常は表示されない安全網)

データキー欠落時に出る文言 (現在は全 10 惑星収録済みなので呼ばれない)。

```
この惑星の解説はまだ準備中です。
```
