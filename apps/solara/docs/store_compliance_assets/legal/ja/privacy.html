Solara プライバシーポリシー

PRIVACY POLICY

Solara は、広大な宇宙のデータを判断材料としてユーザーに提示し、Gemini AI を用いた解釈文章生成を提供するアプリです。本アプリの占い結果は、エビデンス（占星術データ）をもとに導き出される一つの解釈例としてお届けするものです。

本プライバシーポリシー（以下「本ポリシー」といいます）は、林宏治（App Store 版）および arrayu 株式会社（Google Play 版）（以下総称して「当方」といいます）が提供する占星術アプリケーション「Solara」（以下「本アプリ」といいます）における、ユーザーの個人情報の取扱いについて定めるものです。

1. 当方が取得する情報

本アプリでは、以下の情報を取得することがあります。

1-1. ユーザーが本アプリに入力する情報

項目用途
ニックネーム（任意）アプリ内でのユーザー名称表示
生年月日占星術計算
出生時刻占星術計算
出生地（緯度経度）占星術計算
現在の拠点（任意）占星術計算

これらは本アプリの占い機能を提供するために必要な情報であり、ユーザーが任意に入力するものです。ニックネームは本名である必要はありません。

※ 上記の「占星術計算」とは、本アプリが提供する以下のすべての機能における計算入力としての利用を含みます:

  • 出生図・トランジット・プログレスなどの占星術: 出生図（ネイタルチャート）、ハウス計算、アスペクト（120 本）、トランジット（現在の天体位置）、プログレス（進行図）、月相サイクル（新月・満月・刻星化）、144 称号診断 等
  • タロットカードの引きと解釈
  • Stella との相談（Stella 相談機能）
  • 星読み（5 カテゴリ別の解釈文章: 恋愛 / 豊かさ / 仕事 / 対話 / 全体）
  • 地図上のアストロカートグラフィと方位スコア表示: リロケーション（移住占）、方位エネルギー（16 方位）、Daily Transit（10 惑星 × 4 アングル通過時刻）、Forecast（1 年運勢予報）、ACG（アストロカートグラフィー）、Locations（拠点比較）等

1-2. 本アプリの利用に伴い当方が取得する情報

項目用途
地図画面でタップした位置（緯度経度）Stella 相談の計算入力
Sign in 識別子（Apple ID / Google ID）
※ Sign in を行った場合のみ		サブスクリプション復元、複数端末間の同期

端末の改変検知ステータス（root/jailbreak 等の有無）不正利用防止（有料機能のみ無効化、無料機能は影響なし）
占い結果の表示履歴（端末内のみ）過去の結果の再閲覧

1-3. 当方が取得しない情報および GPS の取扱い

  • 本アプリは、デバイスの GPS による現在位置情報を、バックグラウンドで継続取得することはありません。Map 画面で「現在地」機能を利用する場合にのみ、ユーザーの明示的な操作によって一度だけ位置情報を取得し、取得した情報は端末内の地図表示および現在の拠点設定にのみ使用します。取得した位置情報は、当方のサーバーには送信されません。
  • 本アプリは、連絡先・写真・カメラ・マイク・通知などへのアクセスを要求しません。
  • 本アプリは、Google Analytics / Firebase Analytics / 広告 SDK を組み込んでいません。

2. 利用目的

当方は、取得した情報を以下の目的で利用します。

  1. 本アプリの占星術計算結果の表示
  2. Stella による占い解釈テキストの生成
  3. サブスクリプション「Cosmic Pro」の認可および購入復元
  4. 不正利用・端末改変による有料機能の不正解放の防止
  5. 本アプリの動作不具合の調査および改善
  6. 本ポリシー、利用規約、特定商取引法に基づく表記の遵守

3. 情報の保存場所

3-1. 端末内のみに保存される情報

原則として、以下の情報はユーザーの端末内（SharedPreferences）にのみ保存され、当方のサーバーには送信されません。

  • 氏名、生年月日、出生時刻、出生地
  • 現在の拠点情報
  • 占い結果の表示履歴
  • 本アプリの設定情報

3-2. サーバーまたは第三者サービスに送信される情報

本アプリの機能のうち、不正利用防止、Stella による占い解釈の生成、およびサブスクリプション管理においては、以下の情報がインターネット経由で第三者サービスに送信されます。

  • デバイス認証情報（App Attest / Play Integrity）：不正利用防止（デバイス認証）のため、Apple Inc. の App Attest サービス（iOS 版）および Google LLC の Play Integrity サービス（Android 版）に送信されます。匿名のデバイス識別子とアプリ起動情報のみが含まれ、ユーザーの個人情報・占い結果は含まれません。
  • 占星術計算結果（惑星位置、地理座標、相談プロンプト等）：Stella による占い解釈、タロット解釈、星読み、リロケーション解釈の生成のため、当方のサーバー（Cloudflare Workers）経由で Google LLC が提供する Gemini API に送信されます。送信される情報には、ユーザーが入力した相談内容のテキスト、出生情報（生年月日・出生時刻・出生地）、出生図に基づく占星術データ、選択された地理座標が含まれます。これらの情報は解釈生成のために使用された後、Gemini API 側で保持されないよう、Google の規約に基づき処理されます。
  • サブスクリプション識別子（Apple ID / Google Play ID / Sign in ID）と購入情報：課金管理のため、サブスクリプション管理サービス RevenueCat, Inc. に送信され、購入状態の検証および復元のために利用されます。識別子は匿名 ID として扱われます。
  • 地図タイル要求：地図画面の表示のため、当方のサーバー（Cloudflare Workers）経由で OpenStreetMap (OSM Humanitarian) のタイルサーバーに要求が送信されます。ユーザーの個人情報は含まれません。
当方サーバーでの保存方針:
当方が運用する Cloudflare Workers サーバーは、上記の送信内容を恒久的に保存しません。サブスクリプション識別子のキャッシュ（最大 5 分）、および地図タイルのエッジキャッシュ（最大 24 時間）を除き、当方のサーバーにユーザーの個人情報・占い結果は記録されません。

4. 第三者提供

当方は、以下の場合を除き、ユーザーの個人情報を第三者に提供しません。

  1. ユーザーの同意がある場合
  2. 法令に基づく開示要求がある場合（裁判所命令、捜査機関からの照会等）
  3. 本アプリの機能提供のために必要な範囲で、以下の第三者サービスに情報を委託する場合
    • Apple Inc.（App Attest によるデバイス認証〔iOS 版〕、StoreKit 経由のサブスクリプション処理〔iOS 版〕）
    • Google LLC（Play Integrity によるデバイス認証〔Android 版〕、Google Play Billing 経由のサブスクリプション処理〔Android 版〕、Gemini API による占い解釈文章生成〔Stella 相談・タロット・星読み・リロケーション解釈〕）
    • RevenueCat, Inc.（サブスクリプション状態の管理）
    • Cloudflare, Inc.（Worker による API 中継および地図タイル配信）
    • OpenStreetMap Foundation / Humanitarian OpenStreetMap Team（地図タイルの提供）

5. データの削除

ユーザーは以下の方法で本アプリに関連するデータを削除できます。

  • 本アプリ内データの全削除：本アプリをアンインストールすることで、端末内に保存された全データが削除されます。ただし、iOS の iCloud バックアップまたは Android の Google ドライブバックアップが有効な場合、それらの設定に従って一部データがクラウド上のバックアップとして保持されることがあります。バックアップを完全に削除するには、各クラウドサービスの設定からバックアップを個別に削除してください。
  • Sign in 連携の解除：Sanctuary 画面の Account セクションからサインアウトできます。サインアウトすると、RevenueCat 上の本端末との紐付けが解除されます。
  • サブスクリプションの解約：iOS は「設定」アプリ → Apple ID → サブスクリプションから、Android は Google Play Store のメニュー → 定期購入から、それぞれ解約できます。
  • 個人情報の削除請求：当方は原則としてユーザーの個人情報をサーバー上に保持していません（第 3 章参照）。万が一、当方の連携サービス（RevenueCat 等）に残存する情報の削除をご希望の場合、第 9 項のお問い合わせ先までご連絡ください。
