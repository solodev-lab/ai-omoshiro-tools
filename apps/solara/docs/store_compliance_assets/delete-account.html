Solara — アカウント削除のお手続き

Solara をご利用いただきありがとうございます。 アカウントとそれに紐づくデータの削除は、以下の 2 つの方法のいずれかでお手続きいただけます。

削除されるデータ: Pro 契約状況の記録、購入クレジット残高、相談履歴、お気に入り、 端末識別子、ニックネーム、出生情報 (生年月日・出生時刻・出生地)。詳細は本ページ末尾の表をご覧ください。

方法 1: アプリ内から削除する (推奨・即時)

Solara アプリをすでにインストール済みで、サインインされている場合、アプリ内から数タップで削除できます。

  1. Solara アプリを起動します。
  2. 下部ナビゲーションの Sanctuary (✦ マーク) をタップします。
  3. アカウント セクションを開きます。
  4. 「Solara からアカウントを削除」 (赤字) をタップします。
  5. 確認ダイアログの内容をご確認のうえ、 「削除する」 を選択します。 Apple サインインをご利用の場合は、本人確認のため再度サインインを求められます。
削除後の挙動:
  • サーバー上のあなたのアカウントデータは即座に削除されます。
  • Apple サインインをご利用の場合、Apple 側のアプリ連携 (Apple ID 設定 → サインインに使用中のアプリ) からも自動的に解除されます。
  • 有料サブスクリプション (Cosmic Pro) をご契約中の場合、サブスクリプション自体の解約は別途必要です。 解約方法のご案内 をご参照ください。
  • 端末内のローカル設定 (テーマ・お気に入り背景等) もアプリのアンインストールで完全に消去されます。

方法 2: メールでお問い合わせいただく (アプリを削除済みの方)

Solara アプリを既にアンインストール済みで、サーバー上のアカウントデータの削除をご希望の場合は、 以下のメールアドレスまでご連絡ください。

usin.kodima@gmail.com にメールを書く

メールに記載いただきたい情報

  • サインイン方法 (Apple サインイン / Google サインイン / 判らない)
  • 登録時に使用したメールアドレス (わかる範囲で結構です)
  • 最後に Solara を利用した日時 (おおよそで結構です)
  • ご要望: アカウントの完全削除
ご本人確認のお願い: なりすましによる不正な削除を防ぐため、必ずご登録時にお使いいただいたメールアドレスからご送信ください。 別のアドレスからのご依頼の場合、本人確認のため追加情報をお伺いする場合がございます。

対応にかかる時間

メール受信から 7 営業日以内 にお手続きを完了し、完了のご連絡をお送りします。 営業日は土日祝日を除く平日です。年末年始等の長期休業期間は遅延する場合があります。

削除されるデータの一覧

データ種別 保存場所 削除時期
Pro 契約状況の記録 (Cloudflare Workers の内部 DB) Cloudflare Workers / Durable Object 即時
購入クレジット残高 (相談チケット等) 同上 即時
RevenueCat 上の購読者レコード RevenueCat (米) 即時 (REST API 経由で物理削除)
Apple Sign In の連携 (該当ユーザーのみ) Apple ID システム 即時 (Apple Token Revocation 経由)
端末内の設定・履歴 (相談履歴・お気に入り等) 端末ローカル (SharedPreferences) アプリのアンインストール時
サーバー側 Webhook ログ (RevenueCat 経由の購買通知) Cloudflare Workers / Durable Object 即時

例外: 法的義務により保持されるデータ

日本国の電子帳簿保存法および特定商取引法上、購入取引に関する以下の情報のみ、 購入時から 7 年間 保持する必要があります:

  • 取引日時、商品名、価格 (個人を特定しない統計的形態に最小化)

これらの情報は税務上の証憑として保持されるもので、上記の「個人を特定する情報」(メール・出生情報・相談内容等) はすべて削除されます。
