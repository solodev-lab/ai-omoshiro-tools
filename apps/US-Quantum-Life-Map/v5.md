## 1. Technical Fix: The Impeller Y-Coordinate Flip

_Decision: Address the "Upside Down" shader rendering on iOS/Impeller vs. Android/Vulkan._

In Flutter 3.x/4.x (2025-2026), `FlutterFragCoord().y` can be inverted depending on the backend API.

- **The Fix:** Pass a `uFlipY` uniform from Dart based on the platform.
    

### Updated `stella_bg.frag` (Snippet)

OpenGL Shading Language

```

uniform float uTime;
uniform vec2 uSize;
uniform float uFlipY; // 1.0 for Android/Vulkan, -1.0 for iOS/Impeller (context-dependent)

out vec4 fragColor;

void main() {
    vec2 fragCoord = FlutterFragCoord().xy;
    
    // 120% Technical Precision: Coordinate Correction
    if (uFlipY < 0.0) {
        fragCoord.y = uSize.y - fragCoord.y;
    }
    
    vec2 uv = fragCoord / uSize.xy;

}
```
