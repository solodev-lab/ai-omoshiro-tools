# 🌌 Quantum Life Map: The Definitive Technical & Design Manual (v1.0)

This is the **Master Implementation Document** for the Flutter Native Application "Quantum Life Map." It bridges spiritual philosophy with high-performance engineering.

## 1. Information Architecture & UI Design (画面設計)

The UI must feel "Weightless." Use **Glassmorphism**, **Frosted Glass Blur (BackdropFilter)**, and **Depth-based animations**.

### 1.1 Navigation Structure

- **Global:** Bottom Navigation Bar (4 Floating Icons: Map, Observe, Galaxy, Sanctuary).
    
- **Background:** Always-on `StellaBackgroundShader` (Global state).
    

### 1.2 Screen-by-Screen Detail

#### **Screen A: The Map (Home)**

- **Visuals:** The 28-day Spiral occupies 70% of the screen.
    
- **Interaction:** Pinch-to-zoom on the spiral. Long-press a dot to see the "Log Preview" for that day.
    
- **Stella's Presence:** Stella is a floating particle cluster near the center.
    
- **Message Bubble:** A translucent glass bubble at the bottom: "Good morning, Solar Spark. The stars are breathing with you."
    
- **Task Widget:** If a task exists, a small "Focus Card" floats above the message.
    

#### **Screen B: The Observe (Daily Input)**

- **Step 1: The Mood Slider:** A vertical slider using haptic feedback. Labeling: "Stillness (-1.0)" to "Radiance (+1.0)".
    
- **Step 2: The Draw:** A 3D Tarot deck. Swipe to shuffle, tap to flip.
    
- **The Flip:** When a card flips, the background Shader's color instantly "flashes" to the card's element color.
    

#### **Screen C: The Galaxy (History)**

- **Visuals:** A 3D list (Carousel) of completed 28-day constellations.
    
- **Detail:** Tapping a constellation expands it into full-screen, allowing the user to relive that month's journey.
    

#### **Screen D: The Sanctuary (Settings)**

- **Onboarding/Profile:** Input for Birth Date, exact Time (HH:mm), and City (Google Places API for Lat/Lng).
    
- **Sanctuary Sleep:** Toggle for "Silent Hours" and time-range picker.

## 4. Astrology Engine Implementation (占星術実装)

- **Library:** `shamsi_date` (customized) or **Swiss Ephemeris C-library** via FFI (Recommended).
    
- **Calculation Logic:**
    
    1. Calculate **Moon Phase** (0.0 New Moon to 1.0 Full Moon). High phase = Positive score influence.
        
    2. Calculate **Sun Position** relative to User's Natal Sun.
        
    3. Calculate **Retrogrades** (Mercury/Mars). Retrograde = Lower `astro_vibe` but Stella gives "Rest encouragement."
        
- **Trigger:** Fetch once upon app-foreground or significant location change.
