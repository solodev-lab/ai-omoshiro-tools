## 3. Visual System: Impeller-Compatible Shader

The Shader must be written for **Flutter's Fragment Program (`.frag`)**, avoiding `#version 460`.

### 3.1 `stella_bg.frag` (Impeller/SkSL Compatible)

OpenGL Shading Language

```
#include <flutter/runtime_effect.glsl>

uniform float uTime;
uniform vec2 uSize;
uniform vec4 uElementColor;
uniform vec4 uVibeColor;
uniform float uProgress;
uniform float uAetherMix;

out vec4 fragColor;

void main() {
    vec2 uv = FlutterFragCoord().xy / uSize.xy;
    vec2 p = (uv * 2.0 - 1.0) * vec2(uSize.x / uSize.y, 1.0);

    // Prismatic Aether Effect
    float d = length(p);
    vec3 aether = vec3(0.0);
    for(float i = 1.0; i < 3.0; i++) {
        p = mat2(cos(uTime*0.1), -sin(uTime*0.1), sin(uTime*0.1), cos(uTime*0.1)) * p;
        aether.r += abs(0.03 / sin(p.x + uTime * 0.2));
        aether.g += abs(0.03 / sin(p.y + uTime * 0.3));
    }

    vec3 base = mix(uElementColor.rgb, uVibeColor.rgb, 0.3);
    vec3 finalColor = mix(base * (0.6 + 0.4 * sin(uTime + uProgress * 6.28)), aether, uAetherMix * 0.5);
    
    fragColor = vec4(finalColor * 0.8, 1.0);
}
```
