Solara プライバシーポリシー

PRIVACY POLICY

Solara は、広大な宇宙のデータを判断材料としてユーザーに提示し、Gemini AI を用いた解釈文章生成を提供するアプリです。本アプリの占い結果は、エビデンス（占星術データ）をもとに導き出される一つの解釈例としてお届けするものです。

本プライバシーポリシー（以下「本ポリシー」といいます）は、アレイユ株式会社（以下「当方」といいます）が提供する占星術アプリケーション「Solara」（以下「本アプリ」といいます）、および当方が運営するウェブサイト solaramap.com（以下「本サイト」といいます）における、ユーザーの個人情報の取扱いについて定めるものです。

本アプリと本サイトは、取り扱う情報も保存の仕方も異なります。本サイトに固有の事項は、第 1-4 項・第 3-3 項に記載しています。とくに、有料レポートについては、本アプリと異なり当方のサーバーに保存されるものがあります（第 3-3 項）。

3. 情報の保存場所

3-1. 端末内のみに保存される情報

原則として、以下の情報はユーザーの端末内（SharedPreferences）にのみ保存され、当方のサーバーには送信されません。

  • 氏名、生年月日、出生時刻、出生地
  • 現在の拠点情報
  • 占い結果の表示履歴
  • 本アプリの設定情報

3-2. サーバーまたは第三者サービスに送信される情報

本アプリの機能のうち、不正利用防止、Stella による占い解釈の生成、およびサブスクリプション管理においては、以下の情報がインターネット経由で第三者サービスに送信されます。

  • デバイス認証情報（App Attest / Play Integrity）：不正利用防止（デバイス認証）のため、Apple Inc. の App Attest サービス（iOS 版）および Google LLC の Play Integrity サービス（Android 版）に送信されます。匿名のデバイス識別子とアプリ起動情報のみが含まれ、ユーザーの個人情報・占い結果は含まれません。
  • 占星術計算結果（惑星位置、地理座標、相談プロンプト等）：Stella による占い解釈、タロット解釈、星読み、リロケーション解釈の生成のため、当方のサーバー（Cloudflare Workers）経由で Google LLC が提供する Gemini API に送信されます。送信される情報には、ユーザーが入力した相談内容のテキスト、出生情報（生年月日・出生時刻・出生地）、出生図に基づく占星術データ、選択された地理座標が含まれます。これらの情報は解釈生成のために使用された後、Gemini API 側で保持されないよう、Google の規約に基づき処理されます。
  • サブスクリプション識別子（Apple ID / Google Play ID / Sign in ID）と購入情報：課金管理のため、サブスクリプション管理サービス RevenueCat, Inc. に送信され、購入状態の検証および復元のために利用されます。識別子は匿名 ID として扱われます。
  • 地図タイル要求：地図画面の表示のため、当方のサーバー（Cloudflare Workers）経由で OpenStreetMap (OSM Humanitarian) のタイルサーバーに要求が送信されます。ユーザーの個人情報は含まれません。
当方サーバーでの保存方針（本アプリ）:
本アプリについて、当方が運用する Cloudflare Workers サーバーは、上記の送信内容を恒久的に保存しません。サブスクリプション識別子のキャッシュ（最大 5 分）、および地図タイルのエッジキャッシュ（最大 24 時間）を除き、当方のサーバーにユーザーの個人情報・占い結果は記録されません。
本サイトの有料レポートはこの限りではありません。次の第 3-3 項をご確認ください。

3-3. 本サイト（solaramap.com）における保存場所

（1）ユーザーのブラウザ内にのみ保存されるもの

次回の入力を省くため、以下の情報をユーザーのブラウザ内（localStorage）に保存します。当方のサーバーには送信されません。

  • 生年月日、出生時刻、出生地（名称と緯度経度）
  • 表示言語の選択

保存されている間は画面に「この端末に保存しています」と表示され、その横の「消す」からいつでも削除できます。ブラウザのサイトデータの削除でも消去されます。お名前とメールアドレスは、ブラウザ内に保存しません。共用の端末をお使いの場合は、ご利用後に削除されることをおすすめします。

（2）当方のサーバーに保存されるもの（有料レポートのみ）

無料の地図・ホロスコープ・方角の計算では、送信された情報を当方のサーバーに保存しません。有料レポートについては、購入いただいた本をいつでもお読みいただけるようにするため、以下を当方のサーバー（Cloudflare Workers KV）に保存します。

保存するもの保存期間
購入手続きで入力された内容（出生情報・お住まい・お名前等）60 日
注文の記録（作成の進行状況を含む）60 日
決済セッションと注文の対応30 日
完成したレポート本体（作成に用いた出生情報、お名前、メールアドレスを含みます）期間の定めなし（専用リンクを恒久的に有効とするため）
再送のための索引（メールアドレスは SHA-256 で変換した値を鍵として用います）期間の定めなし

レポートは、URL に含まれる推測困難な識別子を知っている方のみが閲覧できます（検索エンジンには登録されません）。削除をご希望の場合は、第 9 項のお問い合わせ先までご連絡ください。

5. データの削除

ユーザーは以下の方法で本アプリに関連するデータを削除できます。

  • 本アプリ内データの全削除：本アプリをアンインストールすることで、端末内に保存された全データが削除されます。ただし、iOS の iCloud バックアップまたは Android の Google ドライブバックアップが有効な場合、それらの設定に従って一部データがクラウド上のバックアップとして保持されることがあります。バックアップを完全に削除するには、各クラウドサービスの設定からバックアップを個別に削除してください。
  • Sign in 連携の解除：Sanctuary 画面の Account セクションからサインアウトできます。サインアウトすると、RevenueCat 上の本端末との紐付けが解除されます。
  • サブスクリプションの解約：iOS は「設定」アプリ → Apple ID → サブスクリプションから、Android は Google Play Store のメニュー → 定期購入から、それぞれ解約できます。
  • 個人情報の削除請求：当方は原則としてユーザーの個人情報をサーバー上に保持していません（第 3 章参照）。万が一、当方の連携サービス（RevenueCat 等）に残存する情報の削除をご希望の場合、第 9 項のお問い合わせ先までご連絡ください。
  • 本サイトのブラウザ内データの削除：本サイトが覚えている生年月日・出生時刻・出生地は、画面の「この端末に保存しています」の横にある「消す」から、いつでもご自身で削除できます。ブラウザのサイトデータの削除でも消去されます。
  • 本サイトの有料レポート・注文情報の削除請求：完成したレポート本体（出生情報・お名前・メールアドレスを含みます）と再送用の索引は、期間の定めなく当方のサーバーに保存されます（第 3-3 項）。削除をご希望の場合は、第 9 項のお問い合わせ先までご連絡ください。削除後は、専用リンクからのご閲覧および再送はできなくなります。

Google APIから受け取る情報の取り扱いは、Google API Services User Data Policy（Limited Use要件を含む）に準拠します。Googleによる情報の取り扱いはGoogleプライバシーポリシーに基づきます。

この連携が扱うのは、当方自身のGoogleアカウントでのOAuth認可と、自社動画をアップロードした際の応答のみです。YouTubeユーザーのデータを当方のサーバーに保存することはありません。この連携のアクセス許可は、いつでもGoogleアカウントの権限設定から取り消せます。
